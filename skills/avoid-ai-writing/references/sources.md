# Avoid AI Writing sources and provenance

This package separates local-policy editing guidance from external references.
External findings are context for an observable prose audit, not evidence of
authorship, plagiarism, or originality.

Scope: package-local source routing for named claims in this skill.

## Sources

- [Tropes.fyi](https://tropes.fyi/) supplies the named trope examples referenced
  in `rhetoric-patterns.md`.
- [StoryScope](https://arxiv.org/abs/2604.03136) is the source for the
  corpus-specific discourse-feature result named in `structural-patterns.md`.
- [Keep a Changelog 1.1.0](https://keepachangelog.com/en/1.1.0/) is cited only
  for the changelog-heading carve-out in `formatting.md`.

## Local policy

Corpus figures labeled as repository observations (including RAID 2024 and HC3
December 2022) are local context without a bundled public source record. Treat
them as writing advice, not as a general detector or a current benchmark.
