# Repo Docs sources and provenance

This package uses local-policy guidance for repository documentation. Examples
use placeholders and do not establish facts about a target repository.

Scope: package-local source routing for standards named by this skill.

## Sources

- [Keep a Changelog 1.1.0](https://keepachangelog.com/en/1.1.0/) supports the
  changelog structure and category names in `docs-changelog.md`.
- [Semantic Versioning 2.0.0](https://semver.org/spec/v2.0.0.html) supports
  the versioning reference in `docs-changelog.md`.
- [BCP 47](https://www.rfc-editor.org/info/bcp47/) supports the language-tag
  naming guidance in `docs-readme.md`.

## Local policy

Verify commands, links, manifests, release history, and translation ownership
against the target repository. No source date or compatibility claim is
inferred from an example.
