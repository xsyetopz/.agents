# Repair examples

These examples show the decision method. They are original illustrations, not
source quotations.

| Candidate | Repair | Why |
| --- | --- | --- |
| Furthermore, the worker retries. | The worker retries. | The transition adds no relationship. |
| Utilize the cache to improve performance. | Use the cache to reduce repeated reads. | Plain verb plus a named effect. |
| The validator serves as a gatekeeper. | The validator rejects malformed input. | State the mechanism. |
| This is a pivotal change. | This change reduces cold-start latency from 900 ms to 240 ms. | Replace praise with evidence. |
| Studies show that the parser is safer. | The project report measures two fewer parser crashes per 10,000 inputs. | Name the source and measure. |
| Not just a refactor. It is a new foundation. | The refactor moves parsing into a separate package. | Remove manufactured contrast. |
| The result? A robust and seamless workflow. | The command retries a failed upload once and reports the server error. | Name behavior and limit. |
| Phase 1: gather requirements. Phase 2: implement. | Gather requirements, then implement the change. | Avoid a numbered march in prose. |
| The service handles retries, logging, and metrics. | The service retries failed requests, writes logs, and exports metrics. | Use concrete verbs; keep the list because it carries facts. |
| The parser uses a robust tokenizer. | The parser uses a tokenizer that rejects unterminated strings. | Keep the actual property. |
| The SQL query must be checked before deployment. | The SQL query must pass the schema check before deployment. | Use `check` for a general gate; keep the schema check specific. |
| “In conclusion, the migration is complete.” | Leave the quotation unchanged unless the user asks to edit the quoted source. | Quoted material is protected. |
| Run bun test before you deploy. | Keep unchanged. | Developer command and surrounding prose are already direct. |
| The fan runs quietly. | Keep unchanged. | Quietly is literal, not a magic adverb. |
